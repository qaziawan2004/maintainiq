 
# MaintainIQ - Asset Maintenance Platform

## Overview
MaintainIQ is an AI-powered QR Maintenance & Asset History Platform that gives physical assets a digital identity, allows users to report issues, helps teams intelligently triage and resolve problems, and preserves a complete maintenance history.

## Features

### Core Features
- ✅ User Authentication (Login/Signup)
- ✅ Asset Management (CRUD operations)
- ✅ Unique Asset Codes with QR Generation
- ✅ Public Asset Pages
- ✅ Issue Reporting & Tracking
- ✅ Maintenance Scheduling
- ✅ Activity History
- ✅ Search & Filter
- ✅ Responsive Design
- ✅ localStorage Persistence

### Bonus Features
- ✅ AI-Powered Insights & Triage
- ✅ Real-time Notifications
- ✅ Analytics Dashboard
- ✅ QR Code Generation & Download
- ✅ Asset History Timeline
- ✅ Bulk QR Label Generation
- ✅ Email Notifications (via localStorage)

## Technology Stack
- HTML5
- CSS3 (Custom with responsive design)
- JavaScript (Vanilla JS)
- Chart.js for analytics
- QRCode.js for QR generation
- localStorage for data persistence
